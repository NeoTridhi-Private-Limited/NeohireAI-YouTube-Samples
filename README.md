# NeohireAI YouTube Samples

Working sample code for the videos on the [NeoTridhi YouTube channel](https://youtube.com/@neotridhi).
Every sample is plain Python 3.10+ and runs offline: a small stand-in model answers each call, so you can
see the ideas work without an API key. Each folder's README shows how to plug in a real model.

## Git and Scion

Sample repos and pipeline files for the Git and Scion series: why Anthropic built Scion, Git from zero to GitHub,
pipelines from commit to deployment, GitHub alternatives and cost, and the future of source control.
Each folder's README lists the commands from the video. The practice repos are shipped without their `.git`
history: rebuild it by following the commands in each README. Scion itself is Anthropic's internal system and
is not released; nothing here is Scion code.

## How to run

    git clone <this repository>
    cd NeohireAI-YouTube-Samples/agent-reading-list/v01_building_effective_agents
    python support_desk.py

Or use **Code > Download ZIP** on GitHub to get everything without git.
